# 前端设计

- 在 `.campaign-table` 内、`.table-head` 上方增加 GET 表单 `.campaign-toolbar`。
- 搜索输入名称为 `q`，回显当前关键字，提供“搜索”按钮。
- 排序下拉框名称为 `sort`，选项为“标题 A → Z”和“标题 Z → A”；变更后可提交表单。
- 存在搜索关键字时提供“清除”链接。
- 无结果且存在关键字时显示针对该关键字的提示；完整列表为空时保留原提示。
- 在 520px 以下让工具栏纵向排列并使控件占满可用宽度。

## 需求 2 用户卡片与预约交互
- operator 活动行使用推导后的展示状态；未来预约活动使用 `status-draft` 视觉和“待发布”文案。
- 用户页未来预约活动显示“待发布”标签及“领取开始 MM月DD日 HH:MM”。
- 未预约时保留领取按钮；点击后显示“未到领取时间，是否预约”确认弹窗。
- 确认按钮调用预约接口，成功后刷新卡片状态；取消按钮只关闭弹窗。
- 已预约卡片右上角显示可访问名称为“已收藏”的星标，并将按钮显示为“已预约”。
- 收藏星标采用卡片绝对定位，工具区预留右侧空间；弹窗复用现有 dialog 视觉并增加双按钮布局。
