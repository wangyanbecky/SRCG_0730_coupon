# 智能项目任务管理平台：初始需求基线

本文件是需求分析的输入，不是已经确认的最终需求。使用时仍需检查目标用户、部署、安全、规模、外部凭证和 AI 边界等关键缺口。

## 产品目标

构建一个本地运行、前后端分离的智能项目任务管理平台，覆盖项目规划、执行、协作、跟踪、汇报、风险管理和自动跟进。Agentic 能力使用 Strands Agents SDK 构建。

## 核心范围

### 项目和任务

- 创建、编辑和维护项目基本信息。
- 管理任务与子任务的完整生命周期，包括创建、分配、状态流转、优先级、截止时间和依赖。
- 提供列表和看板视图，以及常用批量操作。
- 在任务分配和执行过程中支持工作量设定与完成量提交。
- 基于计划工作量、已完成工作量和任务状态统计完成量、完成百分比及项目进度。

### 团队协作

- 用户、团队成员和角色权限管理。
- 项目成员分配、任务协作和权限控制。
- 关键操作保留必要的审计信息。

### 进度和健康度

- 自动汇总任务、子任务和里程碑进度。
- 可视化项目进度与任务完成度。
- 使用红、黄、绿三级项目健康度，并展示触发指标和解释。
- 风险评估考虑逾期比率、任务负载、依赖完成度等维度，提供可操作的缓释建议。

### AI 与 Agent

- 一键生成并润色周报，允许人工编辑和确认。
- AI PM 助手融合企业 RAG，支持自然语言创建项目、生成 WBS、制定验收标准、润色周报和总结会议纪要。
- 自动跟进 Agent 监控阻塞和临期任务，按规则主动提醒和催办。
- 支持智能拉群、生成会议议程和会后纪要。
- AI 输出应可追溯、可人工确认，在模型或知识库不可用时提供降级路径。

### 钉钉集成

- 对关键事件发送钉钉消息通知。
- 在群内提供轻量命令：创建任务、查询进度、检查项目健康度。
- 回调需具备身份校验、权限映射、幂等、重试、限流和失败记录。

### 数据导出

- 导出项目、任务、工作量、进度和状态等基本数据。
- 导出结果遵循用户权限和项目数据隔离规则。

## 需求分析时必须确认

- 本地运行是单机使用、局域网部署还是本地容器化多用户部署。
- 身份认证来源、角色模型和项目级权限矩阵。
- 任务状态集合、允许的转换、完成量单位和完成百分比公式。
- 里程碑与任务/工作量的汇总权重，红黄绿阈值及人工覆盖规则。
- 钉钉机器人/应用模式、组织身份映射、目标消息范围和凭证管理。
- 企业 RAG 的知识源、同步方式、访问控制、引用展示和数据保留。
- 模型提供方、离线要求、成本限制、敏感数据策略和人工确认节点。
- Agent 自动催办频率、静默时段、升级路径、拉群权限和防骚扰策略。
- 首版 MVP 与后续能力边界，以及明确不做事项。
- 预期用户量、项目/任务规模、响应时间、备份和审计要求。
